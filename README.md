# 🔬 电致变色器件 (ECD) — 交互式 3D 模型

> Electrochromic Device — Interactive 3D Model

基于 **Three.js** 的电致变色器件交互式 3D 模型，展示真实 ECD 器件的三层一体结构。含树脂外框、底座、船型开关和内置电池仓。

## ✨ 功能特性

- **🖱 3D 交互** — 拖动旋转、滚轮缩放、右键平移（不自动旋转）
- **💥 分解视图** — 三层结构分离展示，带标签
- **📐 堆叠视图** — 器件如相框般竖立，展示完整成品外观
- **📏 尺寸标注** — 点击按钮显示/隐藏所有尺寸参数（默认隐藏）
- **🖤 树脂边框 & 底座** — 11 cm 黑色外框 + 15×6 cm 底座
- **⚡ 船型开关** — 两档（0/1），拨至 1 档着色，拨回 0 档褪色
- **🔋 内置电池仓** — 6.5×5 cm，两节 AA (5号) 1.5V 电池，完全内嵌底座中
- **📋 详情面板** — 点击任意层查看材料和工作原理

## 🔬 器件结构

| 层号 | 名称 | 规格 |
|------|------|------|
| ① | ITO 透明导电玻璃（上） | 10×10 cm |
| ② | **凝胶变色层** | 10×10 cm，WO₃ 一体化凝胶 |
| ③ | ITO 透明导电玻璃（下） | 10×10 cm |

### 外观组件

| 组件 | 规格 |
|------|------|
| 树脂外框 | 11×11 cm |
| 树脂底座 | 15×6×2 cm |
| 船型开关 | 两档 (0/1)，ON-OFF |
| 电池仓 | 6.5×5 cm，内置底座 |
| 电池 | 2× AA 1.5V 碱性电池 |

## 🚀 使用方式

纯静态 HTML，无需构建工具：

```bash
open index.html
```

## ⌨ 快捷键

| 键 | 功能 |
|----|------|
| `E` | 分解视图 |
| `S` | 堆叠视图 |
| `D` | 尺寸标注 开/关 |
| `A` | 开关变色 |
| `R` | 重置视角 |
| `1-3` | 选择对应层 |
| `ESC` | 关闭详情面板 |
