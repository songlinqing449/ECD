# 🔬 电致变色器件 (ECD) — 交互式 3D 模型

> Electrochromic Device — Interactive 3D Model

基于 **Three.js** 的电致变色器件交互式 3D 模型，展示真实 ECD 器件的三层一体结构。

## ✨ 功能特性

- **🖱 3D 交互** — 拖动旋转、滚轮缩放、右键平移
- **💥 分解/堆叠视图** — 分解视图展示三层结构 + 标签；堆叠视图展示完整器件
- **🖤 树脂边框 & 底座** — 堆叠视图下显示黑色树脂封装边框和底座（分解视图自动隐藏）
- **⚡ 开关变色** — 点击底座上的物理开关（或按 A 键），凝胶层由透明变为**紫罗兰色**
- **📋 层详情面板** — 点击任意层或右侧图例查看详细材料、英文名称和工作原理
- **⌨ 键盘快捷键** — 一键切换所有功能
- **🎨 现代 UI** — 暗色主题、粒子背景、动态光影

## 🔬 器件结构 (3 层)

| 层号 | 名称 | 说明 |
|------|------|------|
| 1 | ITO透明导电玻璃（上） | 玻璃基底 + ITO 导电膜，一体成型 |
| 2 | **凝胶变色层** | 电致变色剂 + 电解质 + 离子存储剂，一体化凝胶 |
| 3 | ITO透明导电玻璃（下） | 玻璃基底 + ITO 导电膜，对电极 |

**堆叠视图额外元素：**
- 🖤 **黑色树脂边框** — 封装密封，保护内部凝胶层，防止水氧侵入
- 🖤 **树脂底座** — 展示支架，集成变色开关
- ⚡ **变色开关** — 点击切换凝胶层透明/紫罗兰色

## ⚙️ 工作原理

```
凝胶层 (透明) + 电压  ⇌  凝胶层 (紫罗兰色)
Li⁺ 注入变色材料       Li⁺ 迁回电解质
```

施加正向电压 → Li⁺ 从电解质注入电致变色材料 → 凝胶变为紫罗兰色
施加反向电压 → Li⁺ 迁回电解质 → 凝胶恢复透明

## 🚀 使用方式

纯静态 HTML，无需构建工具，直接打开即可：

```bash
# 直接打开
open index.html

# 或使用本地服务器
npx serve .
python -m http.server 8080
```

## ⌨ 快捷键

| 键 | 功能 |
|----|------|
| `E` | 分解视图 |
| `S` | 堆叠视图 |
| `A` | 开关变色 |
| `R` | 重置视角 |
| `1-3` | 选择对应层 |
| `ESC` | 关闭详情面板 |
