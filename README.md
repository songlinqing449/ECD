# 🔬 电致变色器件 (ECD) — 交互式 3D 模型

> Electrochromic Device — Interactive 3D Model

基于 **Three.js** 的电致变色器件交互式 3D 模型。展示真实 ECD 器件的三层一体结构，含树脂外框、底座、开关和电池仓。

## ✨ 功能特性

- **🖱 3D 交互** — 拖动旋转、滚轮缩放、右键平移（**不自动旋转**）
- **💥 分解视图** — 三层结构分离展示，带标签，便于观察各层
- **📐 堆叠视图** — 器件如相框般竖立，展示完整成品外观
- **🖤 树脂边框 & 底座** — 黑色树脂封装外框和展示底座
- **⚡ 变色开关** — 底座上的三档六脚拨动开关，点击后凝胶层由透明变为**紫罗兰色**
- **🔋 电池仓** — 底座底部可见电池槽，内置两节 AA (5号) 1.5V 电池
- **📏 尺寸标注** — 堆叠视图下显示关键尺寸数据
- **📋 详情面板** — 点击任意层查看材料和工作原理

## 🔬 器件结构 (3 层)

| 层号 | 名称 | 说明 |
|------|------|------|
| ① | ITO 透明导电玻璃（上） | 10×10 cm，玻璃基底 + ITO 导电膜一体成型 |
| ② | **凝胶变色层** | 10×10 cm，WO₃ + 电解质 + 离子存储一体化凝胶 |
| ③ | ITO 透明导电玻璃（下） | 10×10 cm，对电极 |

### 堆叠视图额外组件

| 组件 | 规格 |
|------|------|
| 树脂外框 | 11×11 cm（外尺寸），内嵌 10×10 cm 玻璃 |
| 树脂底座 | 15×6 cm（长×宽） |
| 拨动开关 | 三档六脚 (ON-OFF-ON)，安装在底座右前方 |
| 电池仓 | 6.5×5 cm，位于底座底部 |
| 电池 | 两节 AA (5号) 1.5V 碱性电池，串联供电 |

## ⚙️ 工作原理

```
WO₃ (透明) + xLi⁺ + xe⁻  ⇌  LiₓWO₃ (紫罗兰色)
```

施加正向电压 (≈+3V) → Li⁺ 从电解质注入 WO₃ → 凝胶变为紫罗兰色  
施加反向电压 (≈-3V) → Li⁺ 迁回电解质 → 凝胶恢复透明  
双稳态特性：断电后颜色保持
